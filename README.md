# Portfolio

My personal site: https://aira-salish.vercel.app

It covers my experience, projects, hackathon results and certificates, with a résumé download and contact links. It's plain HTML, CSS and JavaScript with no build step, and it deploys to Vercel on every push to `main`.

To run it locally:

```bash
python -m http.server 8000
```

- `index.html`: the site
- `img/`, `vid/`: images and project preview clips
- `docs/`: résumé and certificate PDFs
